# MKN Electronics Dubai — Flagship E-Commerce Platform

A production-ready e-commerce platform built for a premier electronics store based in Dubai, United Arab Emirates. Engineered with Next.js 16 (App Router), TypeScript, Tailwind CSS, Three.js 3D hero interactions, Supabase, and full UAE Federal Tax Authority (FTA) tax invoicing compliance.

---

## ⚡ Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack, Partial Prefetching, React 19)
- **Styling & UI:** Tailwind CSS, shadcn/ui design tokens, Framer Motion
- **3D Hero Interaction:** Three.js via `@react-three/fiber` and `@react-three/drei`
- **Database & Auth:** Supabase (Postgres, Row Level Security, Auth, Storage) via `@supabase/ssr`
- **Validation:** Zod + React Hook Form
- **Payments:** Modular Payment Gateway Abstraction (`StripeGateway`, Cash on Delivery, Telr/PayTabs pluggable)
- **Invoicing & PDF:** Client & Server FTA-compliant Tax Invoice PDF generator (`jspdf`, `jspdf-autotable`)
- **Transactional Email:** Resend (`resend`)
- **Hosting Target:** Vercel

---

## 🇦🇪 UAE Legal & Tax Compliance Features

1. **Integer Fils Math:**
   - All monetary figures are stored and processed strictly as integer **fils** (`1 AED = 100 fils`), eliminating floating-point rounding errors.
2. **Sequential Gapless Invoicing:**
   - Tax invoice numbers (`INV-YYYY-XXXXX`) are generated by atomic database sequences in PostgreSQL transactions to ensure strict gapless continuity.
3. **Dual Tax Invoices (FTA Article 59):**
   - **Simplified Tax Invoice:** Automatically generated for B2C retail orders up to AED 10,000.
   - **Full Tax Invoice:** Issued automatically for B2B orders with customer TRN or retail orders exceeding AED 10,000.
4. **PINT AE / Peppol E-Invoicing Ready:**
   - Data model separates `invoices` (header) and `invoice_lines` with standardized tax category codes, ready for UAE E-Invoicing Phase 2 mandate.
5. **5-Year Retention & Immutability:**
   - Invoices cannot be hard-deleted (enforced by PostgreSQL trigger and RLS). Corrections are handled exclusively through Credit Notes (`credit_notes`).
6. **Regulatory Footprint:**
   - Commercial License: **1048291** (Dubai Department of Economy and Tourism - DED)
   - Tax Registration Number (TRN): **100482918200003** (Federal Tax Authority - FTA)

## ⚙️ Environment Configuration

Add the following to your `.env.local` file:

```bash
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL=https://icqovongnsiianjdxdzg.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key

# Payments (Stripe)
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# Transactional Email (Resend)
RESEND_API_KEY=re_...
```

> **Security Note:** Never commit `.env.local` or expose `SUPABASE_SERVICE_ROLE_KEY` to client-side code.

## 🚀 Running Migrations & Seeding Database

1. In your Supabase dashboard or via Supabase CLI, navigate to the SQL Editor.
2. Run the migration file:
   ```bash
   supabase/migrations/20261121000001_initial_schema.sql
   ```
3. Run the demo seed file:
   ```bash
   supabase/migrations/20261121000002_seed_data.sql
   ```

## 🚢 Deploying to Vercel

1. Push this repository to GitHub or GitLab.
2. In Vercel, click **Add New Project** and import the repository.
3. Add the environment variables specified above in Project Settings.
4. Deploy! Next.js 16 will automatically handle static generation and streaming partial prerendering.
